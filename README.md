# Linknest

Полноценное Node.js-приложение для сохранения и обмена ссылками. Пользователи, ссылки и права доступа хранятся в SQLite (`linknest.db`).

## Что реализовано

- регистрация и вход по имени пользователя и паролю;
- ссылки приватны по умолчанию;
- обмен ссылками с зарегистрированными пользователями;
- коллекции, избранное, поиск и отзыв доступа.

## Запуск

```bash
npm install
npm start
```

Откройте `http://localhost:3000`. Перед публикацией скопируйте `.env.example` в `.env` и задайте сильный `JWT_SECRET`.

## Деплой

Для этого Node.js-приложения рекомендую **Render**: подключите репозиторий, выберите сервис *Web Service*, команды `npm install` и `npm start`. Для постоянного хранения БД подключите Render Disk. В качестве альтернативы лучше использовать PostgreSQL (например, Neon/Supabase), поскольку локальный SQLite-файл не подходит для серверлесс-платформ вроде Vercel.
